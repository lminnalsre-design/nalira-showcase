# Nalira

**The operating layer between your work and AI.**

Nalira is an AI-native work operating system that connects projects, goals, tasks, context, AI execution, decisions, and artifacts in a persistent workspace.

## What Nalira Does

- Structures objectives into goals, tasks, and dependencies.
- Connects documents and spreadsheet data as AI context.
- Executes tasks using supported AI models.
- Supports human review and approval of AI-generated results.
- Reuses approved outputs as context for subsequent tasks.
- Maintains project progress and execution history.

## Development Status

Nalira has a working Windows development MVP and is undergoing validation before public early access.

## Technology

Desktop-first application built around Tauri, Rust, React, and TypeScript, with integrations for multiple AI providers.
